1. List 계열

1) Stack
   => First In, Last Out (FILO)
   => 처음 들어간게 마지막에 나온다
   => push() 삽입, pop() 삭제, peek() 확인

2) ArrayList (*)
   => 배열 기반의 리스트
   => 가장 평범하게 많이 사용
   => 인덱스, 값의 중복 허용

3) LinkedList
   => 노드 기반의 연결 리스트
   => 다음 노드의 주소값을 기록해서, 사슬처럼 연결해 놓은 구조
   => ArrayList와 사용 메서드는 똑같음
   => ArrayList보다 삽입, 삭제는 유리하고, 조회는 느림


2. Queue 계열
1) Queue
   => First In, First Out
   => 컴퓨터 운영체제 스케줄링, 다양한 프로그래밍에서 사용
   => 자바에서는 LinkedList를 Queue 에 저장하면 Queue 처럼 사용할 수 있다.
   => 큐의 대표적인 종류
      일반큐 - LinkedList
      양방향큐 - Deque
      우선순위큐 - PriorityQueue

2) Deque
   => 양방향 큐
   => 자바에서는 ArrayDeque클래스로 사용한다.
   => Deque 인터페이스를 상속받음

3) PriorityQueue
   => 값을 넣으면, 자동으로 정렬되는 형태
   => 문자열, 숫자 같은 경우는 자동 정렬되서 들어감
   => 사용자 객체를 쓰게 되면, 정렬의 방식을 반드시 구현해샤 사용할 수 있다.

4. Set 계열
   => 데이터를 중복없이 저장하는 자료구조 (중복X)
   => 해시 알고리즘을 사용해서 저장 순서를 알 수 없음
   => 값의 저장순서를 알수 없어서 get() 메서드가 없다
   => 값의 확인은 iterator라는 반복자로 확인해야 한다
   => HashSet - 기본set클래스
   => TreeSet - 기본set클래스 + 정렬
   => LinkedHashSet

5. Map 계열
   => key, value를 한번에 저장하는 형태의 자료구조
   => 객체 생성시 멀티제네릭 <key, value>에 대한 타입을 동시에 지정해야 한다.
   => key를 알고 있으면, 값을 빠르게 찾아주는 특징을 가짐
   => key를 알고 있으면, 값을 빠르게 찾아주는 특징을 가진다
   => key를 저장하는 방식이 hash개념을 사용해서 저장한다
   => 프로그램 많이 사용된다. put(), get()
   => HashMap<> - 키가 HashSet으로 저장되는 형태
   => TreeMap<> -키가 TreeSet으로 저장되는 형태
   => LinkedHashMap<> - 키가 LinkedHashMap으로 저장되는 형태
